# وثيقة متطلبات النظام: منصة ربط الكفاءات المهنية

نسخة نصية من وثيقة المتطلبات الأصلية (SRS)، مع معرّف لكل متطلب ليُستخدم في التتبع والاختبار. المصدر: "وثيقة متطلبات النظام - منصة الكفاءات المهنية.docx".

## 1. نظرة عامة

**1.1 الغرض:** منصة رقمية بالعربية والإنجليزية، بواجهات احترافية، لحصر الباحثين عن عمل من أبناء القبيلة/العائلة، وبناء قاعدة بيانات دقيقة لكفاءاتهم، وربطهم مباشرة وبموثوقية بأصحاب العمل داخل المملكة وخارجها، مع بيئة إدارة متكاملة، وقابلية للتوسع لخدمات اجتماعية لاحقاً.

**1.2 الفئات المستهدفة:**
- الباحثون عن عمل: أبناء القبيلة الراغبون في فرص وظيفية وتطوير مهاراتهم.
- أصحاب العمل: شركات ومؤسسات وأفراد مسؤولون عن التوظيف، محلياً ودولياً.
- مدراء النظام: إدارة المنصة، مراجعة بيانات أصحاب العمل، ضمان أمنها وسريتها.

## 4. قرارات صاحب المشروع (26 أكتوبر 2026)
- التوثيق بالبريد الإلكتروني الشخصي فقط. لا نفاذ حالياً.
- خدمة SMS تُبنى وتبقى معطلة، وتفعّل في مرحلة تحسين لاحقة.
- التشغيل الأول على جهاز صاحب المشروع للتجربة والعرض، ثم يُقرر مكان الاستضافة.
- الهوية البصرية يقترحها فريق التصميم، وتعدل لاحقاً.
- تحليل السير بـ Claude API يُبنى ويبقى معطلاً حتى يضاف المفتاح.
- صاحب العمل يرى بيانات تواصل الباحث بعد طلب الاهتمام. المحادثة داخل المنصة لاحقاً.
- المدير يعتمد حساب صاحب العمل قبل نشر أي فرصة.

## 5. قرارات اعتماد التصميم (26 أكتوبر 2026)
- صاحب العمل لا يرى رقم هوية الباحث ولا الدار ولا الفخذ. يرى الاسم والعمر والتعليم والخبرات والسيرة ووسيلة التواصل.
- قائمتا الدار والفخذ مستقلتان (`fakhdhs.dar_id` اختياري ويمكن ربطهما لاحقاً).
- "معرّف التواصل والتحقق من الخبرة" = اسم شخص مع رقمه أو بريده يؤكد الخبرة.
- لا يستطيع الباحث سحب طلب الاهتمام في الإصدار الأول.
- رفض حساب صاحب العمل متاح للمدير مع سبب اختياري.
- الاسم المبدئي للمنصة: سَنَد (Sanad)، قابل للتغيير.
- تصدير Excel: المدير يصدّر التقارير وقوائم الباحثين وأصحاب العمل والفرص وطلبات الاهتمام وسجل التدقيق. صاحب العمل يصدّر تقاريره والمهتمين بفرصه فقط. كل تصدير يُسجّل في سجل التدقيق، ورقم الهوية لا يُصدّر إلا مخفياً.
