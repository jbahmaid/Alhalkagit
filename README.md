# منصة ربط الكفاءات المهنية

منصة لحصر الباحثين عن عمل من أبناء القبيلة/العائلة، وبناء قاعدة بيانات لكفاءاتهم، وربطهم بأصحاب العمل داخل المملكة وخارجها.

## الحالة
المرحلة 1 (المعمارية): مسودة بانتظار الاعتماد. راجع [`docs/architecture.md`](docs/architecture.md).

## التشغيل على جهازك (بعد اكتمال البرمجة)
1. ثبّت [Docker Desktop](https://www.docker.com/products/docker-desktop/).
2. انسخ المستودع ثم شغّل في مجلده:
   ```
   docker compose up
   ```
3. افتح `http://localhost:3000`.

ستُضاف تفاصيل حسابات التجربة والعرض على أجهزة أخرى عند انتهاء البرمجة.
