# منصة ربط الكفاءات المهنية (سند)

منصة لحصر الباحثين عن عمل من أبناء القبيلة/العائلة، وبناء قاعدة بيانات لكفاءاتهم، وربطهم بأصحاب العمل داخل المملكة وخارجها. تعمل بالعربية والإنجليزية، وتُخفي هوية صاحب العمل عن الباحثين، وتسجّل كل تغيير في سجل تدقيق، وتعرض تقارير مجمّعة لا تكشف الأفراد.

هذا الدليل لتشغيل المنصة على جهاز ويندوز دون خبرة تقنية. تفاصيل المطورين في [docs/development.md](docs/development.md).

---

## 1. التجهيز (مرة واحدة)

### ثبّت Docker Desktop

1. نزّله من [docker.com/products/docker-desktop](https://www.docker.com/products/docker-desktop/) وثبّته بالإعدادات الافتراضية.
2. أعد تشغيل الجهاز إذا طُلب منك.
3. افتح **Docker Desktop** من قائمة ابدأ، وانتظر حتى يظهر في أسفل النافذة أنه يعمل (**Engine running**، بلون أخضر).
4. اترك Docker Desktop مفتوحاً كلما أردت استخدام المنصة.

### نزّل المشروع

اختر طريقة واحدة:

- **الأسهل:** من صفحة المستودع على GitHub اضغط الزر الأخضر **Code** ثم **Download ZIP**. بعد التنزيل اضغط على الملف بالزر الأيمن ← **Extract All** (استخراج الكل).
- **أو ببرنامج GitHub Desktop:** File ← Clone repository ← اختر المستودع ← Clone. ميزته أن التحديثات لاحقاً بزر **Fetch origin** ثم **Pull**.

### افتح PowerShell داخل المجلد

1. افتح مجلد المشروع في مستكشف الملفات (المجلد الذي فيه الملف `docker-compose.yml`).
2. اضغط على شريط العنوان في أعلى النافذة، واكتب `powershell`، ثم اضغط Enter.
3. تفتح نافذة زرقاء أو سوداء: هنا تكتب الأوامر في هذا الدليل. انسخ الأمر والصقه بالزر الأيمن، ثم اضغط Enter.

## 2. التشغيل

```
docker compose up --build -d
```

- **المرة الأولى تأخذ عدة دقائق** (قد تصل إلى 10–15 دقيقة حسب الإنترنت) لأنها تنزّل وتبني كل شيء. المرات التالية أسرع بكثير.
- لا تحتاج أي إعدادات: كل شيء له قيمة افتراضية.
- للتأكد أن كل شيء يعمل:
  ```
  docker compose ps
  ```
  يجب أن تظهر `healthy` بجانب كل خدمة. الخدمة `minio-init` تعمل مرة واحدة ثم تتوقف، وهذا طبيعي.

### افتح المنصة

| ماذا                                               | الرابط                                         |
| -------------------------------------------------- | ---------------------------------------------- |
| المنصة                                             | [http://localhost:3000](http://localhost:3000) |
| صندوق البريد المحلي (رموز التحقق وكل رسائل المنصة) | [http://localhost:8025](http://localhost:8025) |

## 3. حساب المدير

- اسم الدخول: `admin` (أو البريد `jbahmaid@gmail.com`).
- كلمة المرور المؤقتة: اكتب هذا الأمر في PowerShell وانسخ ما يظهر:
  ```
  docker compose exec api cat /app/secrets/admin-initial-password.txt
  ```
  (تظهر أيضاً داخل مربع في `docker compose logs api`).
- عند أول دخول تُطلب منك كلمة مرور جديدة. احفظها جيداً.
- لإضافة مدير آخر: **المستخدمون** ← **إضافة مدير**. تصله كلمة مرور مؤقتة بالبريد.

### نسيت كلمة مرور المدير؟

1. أنشئ في مجلد المشروع ملفاً اسمه `.env` (بالنقطة في أوله، وبدون امتداد `.txt`) واكتب فيه:
   ```
   ADMIN_RESET_PASSWORD=true
   ```
2. شغّل `docker compose up -d`، ثم خذ كلمة المرور المؤقتة بالأمر السابق.
3. احذف السطر من `.env` بعدها، وإلا تتغير كلمة المرور في كل تشغيل.

> طريقة إنشاء `.env` من المفكرة (Notepad): اكتب السطر، ثم File ← Save As، واختر **Save as type: All Files**، واكتب الاسم `.env`.

## 4. بيانات العرض (للتجربة فقط)

تضيف المنصة بيانات تجريبية لتظهر الشاشات والتقارير ممتلئة: 40 باحثاً، و7 أصحاب عمل (واحد منهم بانتظار الاعتماد)، و20 فرصة، وطلبات اهتمام، وبعض السير الذاتية.

**طريقة 1 (تبقى مفعلة):** أضف إلى ملف `.env`:

```
SEED_DEMO=true
```

ثم شغّل `docker compose up -d`.

**طريقة 2 (مرة واحدة):** والمنصة تعمل:

```
docker compose exec api node dist/demo.js seed
```

### حسابات العرض

كلها بكلمة المرور **`Demo-Sanad-2026`**:

| الدور                       | البريد                                                        |
| --------------------------- | ------------------------------------------------------------- |
| مدير                        | `admin@demo.sanad.local`                                      |
| صاحب عمل                    | `employer1@demo.sanad.local` إلى `employer6@demo.sanad.local` |
| صاحب عمل (بانتظار الاعتماد) | `employer7@demo.sanad.local`                                  |
| باحث عن عمل                 | `seeker01@demo.sanad.local` إلى `seeker40@demo.sanad.local`   |

> **تحذير:** كلمة المرور هذه مكتوبة هنا وفي سجل الخدمة، فهي معروفة للجميع. **لا تفعّل بيانات العرض أبداً على منصة حقيقية فيها بيانات أشخاص.**

### حذف بيانات العرض

1. اجعل `SEED_DEMO=false` في `.env` (أو احذف السطر)، حتى لا تعود عند التشغيل التالي.
2. شغّل:
   ```
   docker compose exec api node dist/demo.js remove
   ```

يحذف هذا كل حسابات `@demo.sanad.local` وفرصها وطلباتها وسيرها، ولا يمس أي بيانات أخرى.

## 5. البريد

لا تخرج أي رسالة من جهازك ما دام البريد على الإعداد الافتراضي. كل رسالة (رمز التحقق، كلمة مرور مدير جديد، استعادة كلمة المرور) تظهر في [http://localhost:8025](http://localhost:8025).

لإرسال بريد حقيقي، ضع إعدادات خادم البريد `SMTP_*` في `.env` (موثقة في [`.env.example`](.env.example)).

---

## 6. الفتح من أجهزة أخرى في نفس الشبكة

1. اعرف عنوان جهازك: اكتب في PowerShell:
   ```
   ipconfig
   ```
   وخذ الرقم بجانب **IPv4 Address** (مثل `192.168.1.20`).
2. من الجوال أو الجهاز الآخر (على نفس الواي فاي) افتح: `http://192.168.1.20:3000`
3. حتى تعمل الروابط في رسائل البريد بهذا العنوان، أضف إلى `.env`:
   ```
   PUBLIC_URL=http://192.168.1.20:3000
   ```
   ثم شغّل `docker compose up -d`.
4. إذا سألك ويندوز عن جدار الحماية لـ Docker، اختر **Private networks** (الشبكات الخاصة) واضغط **Allow**. إن لم يسألك ولم تفتح الصفحة: إعدادات ويندوز ← الخصوصية والأمان ← أمن Windows ← جدار الحماية وحماية الشبكة ← السماح لتطبيق عبر جدار الحماية ← فعّل Docker Desktop للشبكات الخاصة.
5. **لعرض أمام مجموعة:** في Docker Desktop تظهر كل الأجهزة للمنصة بعنوان واحد، فتشترك في حد الطلبات (مثلاً 10 محاولات دخول في الدقيقة للجميع). أضف إلى `.env`:
   ```
   THROTTLE_FACTOR=10
   ```
   ثم `docker compose up -d`. قفل الحساب بعد محاولات خاطئة يبقى فعالاً.

## 7. الإيقاف والتشغيل والبدء من جديد

| الأمر                          | ماذا يفعل                                                                               |
| ------------------------------ | --------------------------------------------------------------------------------------- |
| `docker compose stop`          | يوقف المنصة، والبيانات محفوظة                                                           |
| `docker compose up -d`         | يشغّلها من جديد                                                                         |
| `docker compose up --build -d` | يشغّلها بعد تنزيل نسخة أحدث من المشروع                                                  |
| `docker compose down`          | يوقفها ويحذف الحاويات، والبيانات محفوظة                                                 |
| `docker compose down -v`       | **تحذير: يحذف كل البيانات** ويبدأ من الصفر: الحسابات، السجل، المفاتيح، كلمة مرور المدير |

بعد إعادة تشغيل الجهاز: افتح Docker Desktop وانتظر Engine running، ثم `docker compose up -d` من مجلد المشروع.

## 8. مشكلات شائعة

| المشكلة                                                                                                        | الحل                                                                                                                                                                                                     |
| -------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `error during connect` أو `The system cannot find the file specified` أو `Cannot connect to the Docker daemon` | Docker Desktop غير مفتوح. افتحه وانتظر **Engine running** ثم أعد الأمر.                                                                                                                                  |
| رسالة تطلب تحديث WSL، أو Docker Desktop لا يبدأ                                                                | افتح PowerShell **كمسؤول** (زر أيمن على PowerShell ← Run as administrator) واكتب `wsl --update`، ثم أعد تشغيل الجهاز. إن ظهر أن المحاكاة الافتراضية (Virtualization) معطلة فيجب تفعيلها من إعدادات BIOS. |
| `port is already allocated` أو `Bind for 0.0.0.0:3000 failed`                                                  | برنامج آخر يستخدم المنفذ 3000. أضف إلى `.env` السطر `WEB_PORT=3001` وشغّل `docker compose up -d`، وافتح `http://localhost:3001` (وغيّر `PUBLIC_URL` بنفس الرقم). للمنفذ 8025 استخدم `MAILPIT_PORT`.      |
| `no configuration file provided: not found`                                                                    | PowerShell ليس في مجلد المشروع. افتحه من شريط العنوان داخل المجلد الذي فيه `docker-compose.yml`.                                                                                                         |
| الصفحة لا تفتح بعد التشغيل مباشرة                                                                              | انتظر دقيقة ثم حدّث الصفحة. `docker compose ps` يجب أن يُظهر `healthy`.                                                                                                                                  |
| البناء الأول توقف بخطأ شبكة                                                                                    | تأكد من الإنترنت وأعد `docker compose up --build -d`، فيكمل من حيث توقف.                                                                                                                                 |
| "محاولات كثيرة. انتظر دقيقة ثم حاول مجدداً." أثناء عرض جماعي                                                   | انظر البند 5 في القسم 6 (`THROTTLE_FACTOR`).                                                                                                                                                             |
| لا يصل رمز التحقق                                                                                              | افتح صندوق البريد المحلي [http://localhost:8025](http://localhost:8025).                                                                                                                                 |

لعرض سجل أي خدمة لمعرفة سبب مشكلة: `docker compose logs api` (أو `web` أو `worker`).

## 9. الإعدادات الاختيارية

كل الإعدادات موثقة في [`.env.example`](.env.example). انسخه باسم `.env` وغيّر ما تحتاجه فقط. أهمها:

- `SMTP_*`: إرسال بريد حقيقي.
- `SMS_ENABLED`: الرسائل النصية، معطلة افتراضياً.
- `CV_ANALYSIS_ENABLED` و`ANTHROPIC_API_KEY`: التحليل الآلي للسير الذاتية، معطل افتراضياً. يُرسل نص السيرة فقط، دون الاسم أو الهوية أو بيانات التواصل.
- المفاتيح السرية تُولَّد تلقائياً في أول تشغيل وتُحفظ داخل Docker. لا تُكتب في المستودع أبداً.
